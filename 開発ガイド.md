## 開発環境セットアップ

### 必要な環境

- **OS**: macOS / Linux / Windows
- **Java**: OpenJDK 21以上
- **Kotlin**: 2.3.0-RC (自動ダウンロード)
- **Maven**: 3.9.x以上
- **PostgreSQL**: 14以上
- **Node.js**: 18以上（フロントエンド開発時）
- **Git**: 2.30以上
- **IDE**: JetBrains IntelliJ IDEA (推奨)

### 1. リポジトリのクローン

```bash
git clone https://github.com/yourusername/Kotlin_SpringBoot.git
cd Kotlin_SpringBoot
```

### 2. PostgreSQL の起動

**Docker を使用する場合:**

```bash
docker-compose up -d postgres
```

**ローカルインストールの場合:**

```bash
# macOS (Homebrew)
brew install postgresql@14
brew services start postgresql@14

# Linux (Ubuntu)
sudo apt-get install postgresql postgresql-contrib
sudo systemctl start postgresql
```

### 3. データベースの初期化

```bash
# psql で接続
psql -U postgres

# データベース作成
CREATE DATABASE timesheet_db;
CREATE USER timesheet_user WITH PASSWORD 'password';
GRANT ALL PRIVILEGES ON DATABASE timesheet_db TO timesheet_user;
```

### 4. 環境変数の設定

**src/main/resources/application-dev.yml** を作成:

```yaml
spring:
  datasource:
    url: jdbc:postgresql://localhost:5432/timesheet_db
    username: timesheet_user
    password: password
    driver-class-name: org.postgresql.Driver

  jpa:
    properties:
      hibernate:
        dialect: org.hibernate.dialect.PostgreSQLDialect

  profiles:
    active: dev

server:
  port: 8080
```

### 5. Maven ビルド

```bash
# 依存関係のダウンロードとビルド
mvn clean install -DskipTests

# テストを実行
mvn test

# アプリケーション起動
mvn spring-boot:run
```

### 6. 動作確認

```bash
# ヘルスチェック
curl http://localhost:8080/home

# ログイン画面が表示されれば OK
```

### SQL 規約

#### ファイル構成

```xml

<!DOCTYPE mapper

        "http://mybatis.org/dtd/mybatis-3-mapper.dtd">

    <select id="selectByUserAndDate"
            parameterType="map"
            resultType="com.example.demo.model.TimesheetEntry">

        WHERE user_name = #{userName}
        AND work_date = #{workDate}
        AND deleted = FALSE
    </select>

    <insert id="insert" parameterType="com.example.demo.model.TimesheetEntry">
        INSERT INTO timesheet_entries (
        work_date, user_name, start_time, end_time, ...
        ) VALUES (
        #{workDate}, #{userName}, #{startTime}, #{endTime}, ...
        )
    </insert>

</mapper>
```

**Step 3: Mapper インターフェース更新**

```kotlin
// mapper/TimesheetEntryMapper.kt
@Mapper
interface TimesheetEntryMapper {
    @Update("UPDATE timesheet_entries SET free_note = #{freeNote}, version = version + 1 WHERE id = #{id} AND version = #{version}")
    fun updateFreeNote(entry: TimesheetEntry): Int
}
```

**Step 4: Service 実装**

```kotlin
// service/TimesheetService.kt
@Transactional
fun saveFreeNote(userName: String, freeNote: String): TimesheetEntry {
    val today = LocalDate.now()
    val existing = timesheetEntryMapper.selectByUserAndDate(userName, today)
        ?: throw TimesheetNotFoundException("本日のタイムシートがありません")

    val updated = existing.copy(freeNote = freeNote)
    val updatedCount = timesheetEntryMapper.updateFreeNote(updated)

    if (updatedCount == 0) {
        throw TimesheetConflictException("同時更新により保存できませんでした")
    }

    eventPublisher.publishEvent(TimesheetUpdatedEvent(userName, today))
    return updated
}
```

**Step 5: Controller 実装**

```kotlin
// controller/TimesheetController.kt
@PostMapping("/free-note")
fun saveFreeNote(auth: Authentication, @RequestBody body: Map<String, String>): TimesheetEntry {
    val freeNote = body["freeNote"] ?: ""
    val entry = timesheetService.saveFreeNote(auth.name, freeNote)
    broadcast("free-note", entry, auth.name)
    return entry
}
```

## テストの書き方

### ユニットテスト（単体テスト）

```kotlin
// test/kotlin/com/example/demo/service/TimesheetServiceTest.kt
import org.junit.jupiter.api.Test
import org.junit.jupiter.api.BeforeEach
import org.mockito.Mock
import org.mockito.kotlin.whenever
import kotlin.test.assertEquals

class TimesheetServiceTest {
    @Mock
    private lateinit var mapper: TimesheetEntryMapper

    private lateinit var service: TimesheetService

    @BeforeEach
    fun setup() {
        service = TimesheetService(mapper, eventPublisher)
    }

    @Test
    fun `clockIn should create new entry when none exists`() {
        // Arrange
        val userName = "test_user"
        val today = LocalDate.now()
        whenever(mapper.selectByUserAndDate(userName, today)).thenReturn(null)
        whenever(mapper.insert(any())).thenReturn(1)

        // Act
        val result = service.clockIn(userName)

        // Assert
        assertEquals(userName, result.userName)
        assertEquals(today, result.workDate)
        assertNotNull(result.startTime)
    }

    @Test
    fun `clockOut should fail if not clocked in`() {
        // Arrange
        val userName = "test_user"
        val entry = TimesheetEntry(
            id = 1, workDate = LocalDate.now(), userName = userName,
            startTime = null, endTime = null
        )
        whenever(mapper.selectByUserAndDate(userName, LocalDate.now()))
            .thenReturn(entry)

        // Act & Assert
        assertThrows<TimesheetConflictException> {
            service.clockOut(userName)
        }
    }
}
```

### 統合テスト


## よくある質問

### Q1: テストなしでビルドできますか？

**A**: `mvn clean package -DskipTests` で可能ですが、本番環境では非推奨です。

### Q2: ログの詳細度を上げるには？

**A**: `logging.level.root=DEBUG` を application.yml に設定してください。

### Q3: PostgreSQL に接続できません

**A**: 以下を確認:

1. PostgreSQL が起動している: `brew services list`
2. ユーザー・パスワードが正しい
3. データベースが存在する: `psql -U postgres -l`

### Q4: ポート 8080 が既に使用されている

**A**: `server.port=8081` で別ポートに変更するか、既存プロセスを停止してください。

### Q5: 環境変数の読み込みがうまくいきません

**A**: 環境変数は起動時に設定してください:

```bash
export DB_PASSWORD=secret
java -jar app.jar
```
